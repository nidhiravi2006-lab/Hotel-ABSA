Aspect results and method

Five aspect models plus overall sentiment. We choose each model using validation macro-F1 and measure it once on the test set. Rating and sentiment use independent models, so they can disagree. Keyword evidence is a heuristic, and a missing keyword does not prove an aspect is absent. The supplied paper uses a different dataset and protocol.
